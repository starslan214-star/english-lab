# English Lab

当前产品版本：**1.1.0**

面向英语初学者的软件测试英语学习网站。默认中文界面，可切换英文；保留英文单词、例句和阅读原文，并提供中文辅助。

## 本地开发

项目不依赖第三方 npm 包，使用 Node.js 运行构建和检查：

```bash
npm run build
npm test
npm run preview
```

本地预览地址为 `http://127.0.0.1:4175/`。修改 `dist/` 前端文件或 `worker/` 服务端文件后，必须重新运行 `npm run build`，生成最新的 `dist/server/index.js`，再重新启动预览服务。

## 我的图书库与数据备份

「我的图书」支持粘贴英文文章，或导入 TXT、Markdown 文件。正文只保存在当前浏览器，不上传服务器；阅读时可点击任意英文单词进入词典查询，并可通过浏览器打印保存为 PDF。

图书库页面可以导出完整 JSON 备份，内容包含单词掌握度、复习记录、阅读记录、学习笔记和本地图书。恢复备份时会与当前浏览器中的数据合并。当前版本尚未加入 EPUB、扫描 PDF 解析和跨设备云同步。

## DeepSeek AI 助教

打开网站的「AI 助教」，输入自己的 DeepSeek API Key，点击「验证并连接」。成功后即可选择 DeepSeek Flash 或 V4 Pro，进行单词解释、句子分析、故事生成和小测验。

助教对话使用 DeepSeek 的非思考模式，适合直接返回简短学习答案。若上游返回空内容或达到输出长度上限，页面显示明确错误，可缩短问题后重试。

密钥经网站服务端验证，通过 AES-GCM 加密后保存在当前浏览器的 HttpOnly、Secure、SameSite=Strict 会话 Cookie 中。网页脚本无法读取或回显保存后的密钥。关闭浏览器后通常需要重新输入。聊天内容会发送到 DeepSeek，模型调用可能产生费用。

部署时必须将 `ENGLISH_LAB_COOKIE_KEY` 设为 32 字节随机值的十六进制字符串，并标记为服务端密钥。不要把它或 DeepSeek API Key 写入代码仓库。

## 词库与分类

词汇页现有 5,765 个去重词条，来自 [WordTyper 开放词库](https://github.com/grhliu/wordtyper-vocabularies) 的四级和六级数据，以及原有的情境词。站内过滤掉少量不适合单词卡的特殊条目后，四级筛选有 3,814 个词，六级筛选有 5,370 个词；重合词同时带两个标签，因此两个数字不能相加。考试标签仅作备考参考，不代表官方完整大纲或考试机构认证。

场景标签是从词库中人工挑选的常用词，可与考试级别组合筛选；未贴场景标签的词仍在「全部场景」中。支持英文和中文释义搜索、分页、朗读、标记已学和复习。学习数据仍保存在原浏览器记录中。

词条的中文释义和音标可离线使用。词典页支持中文或英文查询，优先显示站内 ECDICT 派生词条；英文词条的词性、英英释义和例句按需从 [Free Dictionary API](https://dictionaryapi.dev/) 读取。词典查询不限定在背词表中。连接自己的百度翻译后，可查询背词表外的中英文词语或短句。

## 百度翻译连接

在词典页的「连接百度翻译」区域输入「通用文本翻译」的 APP ID 与密钥，并点击「验证并连接」。服务端通过百度官方接口验证凭据。通过后，凭据经 AES-GCM 加密保存在当前浏览器的 HttpOnly、Secure、SameSite=Strict Cookie 中；页面脚本不会读取或回显密钥。断开连接会清除 Cookie。查询文本会发送到百度翻译，调用量及费用以用户自己的百度账户为准。

百度通用文本翻译只返回翻译文本，不提供词性、固定搭配等完整词典字段。词典页会把翻译与 ECDICT、Free Dictionary API 的结果分开显示；对当前数据源没有可靠内容的搭配和用法板块明确标记为待补充。

如果百度返回 `58003`，按[官方文档](https://api.fanyi.baidu.com/doc/23)是调用来源 IP 当日被封禁，通常次日解除。本站服务端可能使用共享出口 IP；正常使用仍被误封时，可按照百度文档联系其支持邮箱。词典页另外提供按需调用已连接 DeepSeek 的「AI 助教补充」，用来生成搭配、用法和例句，并明确标记为 AI 生成内容。

「学习笔记」页面可保存从词典查询的词语或句子、记录自己的注释，并导出 Markdown。笔记仍保存在当前浏览器，请定期导出；跨设备同步尚未接入。

单词页提供「到期复习」队列。首次标记已学会安排次日复习，之后根据「没记住／有点难／记住了／很简单」调整间隔；原有已学但没有复习日期的词会先进入到期队列。该实现是面向日常学习的简化间隔复习，不是完整 FSRS。

「设置」页面可查看 DeepSeek 与百度翻译的连接状态，下载包含单词、复习、阅读、游戏和笔记的 JSON 备份，也可合并导入旧备份。备份不包含任何 API 密钥。

有道正式词典 API 需要单独开通，欧路公开接口主要用于个人生词本；两者目前只显示接入状态说明，不冒充已接入的词典结果。

百度 API 签名使用 [blueimp JavaScript-MD5](https://github.com/blueimp/JavaScript-MD5) 的 MIT 授权实现，版权声明见 `LICENSES/blueimp-md5-MIT.txt`。

数据源为 [ECDICT](https://github.com/skywind3000/ECDICT) 的 MIT 授权派生数据，许可证与来源说明保存在 `LICENSES/`。若要重新生成词库，在本地取得 WordTyper 的 `cet4.json` 和 `cet6.json` 后运行 `node scripts/make-vocab.mjs <四级文件> <六级文件>`。

## 当前范围

词汇、A1 阅读练习和日志是入门内容。「阅读」页另从 Google AI 和 Selenium 官方博客读取近期文章的标题、日期和原文链接，每 20 分钟更新一次；文章原文留在官方站点。若来源暂时不可用，站内分级练习仍可使用。牛津与有道的付费或专用 API、跨设备同步和自动写入 Obsidian 尚未接入。
