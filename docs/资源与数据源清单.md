### 已接入 ✓

|---|---|---|---|
| [ECDICT](https://github.com/skywind3000/ECDICT)（MIT） | `ecdict.csv` 约 77 万条：音标、中/英释义、考试标签（zk/gk/cet4/cet6/ky/toefl/ielts/gre）、**BNC(`bnc`)/COCA(`frq`) 词频、牛津3000标记(`oxford`)、柯林斯星级(`collins`)、词形变化(`exchange`)** | MIT（来源声明存于 `LICENSES/`） | 站内离线词典 + 词库中文释义底座（已接入）；打标直接用这些字段。⚠️ 大陆下载 raw 大文件不稳，走 Releases/npm(`ecdict`)/jsDelivr 镜像 |
| [WordTyper 词库](https://github.com/grhliu/wordtyper-vocabularies) | 四级 3,814 词 / 六级 5,370 词（去重后 5,765） | 开放词库（声明见 `LICENSES/WORDTYPER-NOTICE.md`） | 背词表主体（已接入） |
| [kajweb/dict](https://github.com/kajweb/dict) | 打包词书 JSON（四六级/考研/雅思托福/GRE 等）：每词含英美音标、**2-3 句带中文翻译的例句**、近义词、短语、真题选择题 | ⚠️ **无许可证**（爬取有道背单词数据）——个人本地自用风险低，**禁止再分发/商用** | 例句与词书顺序层，与 ECDICT 按 word 字段 join；可满足例句需求，Tatoeba 只作补充 |

### 建议补充

| 资源 | 内容 | 许可证 | 用法 |
|---|---|---|---|
| [CEFR-J Wordlist 1.6](http://www.cefr-j.org/download.html) | 7,801 词条标注 **A1–B2**（目前唯一免费、可商用引用的成体系 CEFR 词表；EVP 无开放数据） | 非 CC；官方声明正确引用后研究/教育/商用均可 | **A1–B2 分级映射主力**（B2 以上用 ECDICT 词频推断）——V2 阅读难度引擎和词库排序都靠它 |
| [NGSL 新通用词表](https://www.newgeneralservicelist.com/) | 约 2,809 高频核心词（覆盖一般文本 ~90%），另有 NAWL/TSL 等 10 个词表 | 官网声明 CC、**允许商用**（具体 CC 变体未标明），引用 Browne, Culligan & Phillips | 零基础先学高频词；给词库加 `ngsl` 优先级标签 |
| [ISTQB 术语表 v4.7.2](https://glossary.istqb.org) | 软件测试术语中英对照（CSTQB 提供官方中文对照 PDF） | © ISTQB：**允许整体复制或摘录 + 注明来源；改编未明确授权** | Software Testing 路线的术语打标与术语卡；只做原样词条引用，不做改写 |
| [Tatoeba](https://tatoeba.org) | 数百万条按词检索的例句；`sentences_CC0.csv` 有 34 万+ **CC0 零负担子集** | CC-BY 2.0 FR（CC0 子集无要求） | 例句补充库：新词卡自动配真实例句，可完全离线自建索引 |
| WordNet 3.1（[Princeton](https://wordnet.princeton.edu)） | 同义词/上下位词语义网络（无中文） | 宽松许可（"unencumbered"，商用可用，需引用文献） | 可选：同义词扩展、词根联想 |
| COCA/BNC 词频 | 词频排序（ECDICT 自带 `bnc`/`frq` 字段已够用） | 数据开放 | 词库默认排序按词频，高频先学 |

> 结论：你的词库「底座已经够了」，缺的是**打标**（Daily/Testing/AI 三路线 + CEFR 分级，见开发计划 0.4）而不是更多词量。优先级：打标（CEFR-J + ECDICT 字段）> kajweb 例句导入 > NGSL。

## 二、词典 API（分层接入）

| 层 | 服务 | 提供什么 | 费用/额度（2026-09 核实） | 状态 |
|---|---|---|---|---|
| 离线层 | ECDICT（本地数据） | 音标 + 中/英释义 | 免费 | ✓ 已接入 |
| 英英层 | [Free Dictionary API](https://dictionaryapi.dev) | 英英定义、音标、音频（Wikimedia Commons）、同义词；实测在线 | 免费、无 key；数据源 Wiktionary（**CC BY-SA 3.0**），响应可缓存后完全离线 | ✓ 已接入（限流偶发：本地缓存 + 重试，勿高频调用） |
| 英英层 | Merriam-Webster API | Learner's 英英释义 + 同反义词（Thesaurus）+ 真人音频 | 非商业免费，**每 key 1,000 次/天**，注册即得 | 计划接入（V1 任务 1.6） |
| 相关词 | [Datamuse](https://www.datamuse.com/api/) | 同义词、**搭配 rel_trg**、相关词、前缀补全 | 免费、无 key、10 万次/天（⚠️ 免 key 政策官网标注至 **2027-01-01**，到期复查） | 计划接入 |
| 翻译层 | 百度翻译通用文本翻译 | 词/句翻译 | 标准版 5 万字符/月；**个人认证（高级版）100 万字符/月、QPS 10**；超出 49 元/百万字符 | ✓ 已接入（服务端代理）→ 建议做个人认证升级到高级版 |
| 翻译层（备选） | DeepL API Free | 高质量句子翻译 | 50 万字符/月免费（官方支持文档已确认） | 大陆可达性未核实，作备选 |
| AI 层 | DeepSeek / 任意 OpenAI-compatible | 搭配、用法、辨析、例句（标注 AI 生成） | 用户自己的 key | ✓ 已接入 |
| 跳转 | Oxford Learner's Dictionaries 网页 | 权威学习者释义 | 免费 | ✓ 已做外链跳转 |

> **牛津 Dictionaries API：免费层已取消**（2026 核实，最低 Prototype 档 **£50/月（年付）**仅含 1,000 次调用）——原计划里「Oxford 提供 Sandbox 试用」的信息已过时，**直接排除**。其价值（CEFR 标注、学习型英英释义）由 CEFR-J + Free Dictionary API + ECDICT 组合替代。商业词典（牛津高阶等）词条库不可爬取入库，正确姿势就是现在的「应用内跳转」。

**发音方案**（全部实测可用）：Web Speech API（主，系统语音离线可用；注意 Chrome 桌面部分语音走 Google 服务器，大陆可能无声，选系统本地语音）+ 有道 `dict.youdao.com/dictvoice?audio=word&type=1|2`（真人音，国内直连快，type=1/2 对应英美音建议自听确认后固定；非官方接口，个人使用无碍）+ Free Dictionary API 自带 mp3。**首次播放即缓存到 IndexedDB，最终形态完全离线。**

## 三、外刊阅读源（已逐个实测抓取）

### 版权分级（工程上落到 `license_mode` 字段：full / title_only）

- 🟢 **绿灯（可全文入库 + AI 改写 + 应用内重发布）**：VOA Learning English（美国联邦政府作品，公有领域，署名 VOA；避开 AP/Reuters 稿）、Simple English Wikipedia（CC BY-SA 4.0，改写产出须同许可）、Selenium/Playwright GitHub Releases（Apache-2.0）。
